# 🎙️ TranskriptPro

> AI-powered audio and video transcription desktop application for Windows.

![Platform](https://img.shields.io/badge/platform-Windows-blue)
![Python](https://img.shields.io/badge/python-3.10-green)
![License](https://img.shields.io/badge/license-MIT-orange)

## ✨ Features

- 🤖 **AI Transcription** — Powered by Faster-Whisper (Turbo mode)
- 👥 **Speaker Diarization** — Automatically identifies who said what
- 🎙️ **Dual-Channel Recording** — System audio and microphone transcribed separately
- 🖥️ **Screen + Audio Recording** — Capture your screen with synchronized audio
- 📁 **Batch Processing** — Add multiple files to the queue
- 🌐 **Auto Translation** — Transcribe and translate simultaneously
- 🔄 **Auto Update** — Notifies you when a new version is available
- 🌍 **Multilingual UI** — Turkish and English interface

## 🚀 Getting Started

1. Go to [Releases](../../releases) and download the latest `.exe`
2. Copy the file into a dedicated folder
3. Run — no installation required
